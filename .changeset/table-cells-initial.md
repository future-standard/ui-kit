Standard cell library: `createTableCells()` with number, bytes, duration, boolean, timestamp,
multiline, status, thumbnail, link, actions, switch, progress, truncate and icon renderers, all
configured from JSON schema options with JSON-safe conditions. `@future-standard-ui/table` gains the
`onCellAction` channel (`emit` in the cell context). Theme gains `--table-cell-*` aliases.
